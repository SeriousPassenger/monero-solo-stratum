# Runtime image placeholders

Operator screenshots are intentionally not fabricated. Add the final captures
with these filenames, then replace the placeholder list in the main README with
the prepared Markdown image links:

- `watch-status-split.png`: both panes, including peer/difficulty/verifier and
  compact host-load groups;
- `watch-status-export.png`: paused event stream with multiple selected rows
  and the JSON filename dialog visible.

Capture a real runtime with secrets and identifying connection data outside the
frame. Prefer a terminal at least 120 columns wide for the split image and keep
text readable at the repository page's normal rendered width.
